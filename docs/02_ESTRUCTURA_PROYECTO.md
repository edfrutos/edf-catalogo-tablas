# Estructura del proyecto

## Directorios principales

- `app/`: aplicación Flask.
- `app/routes/`: rutas principales, administración y catálogos.
- `app/templates/`: plantillas Jinja.
- `app/static/`: JavaScript, CSS e imágenes estáticas.
- `tools/`: utilidades auxiliares.
- `docs/`: documentación consolidada.

## Plantillas principales

- `base.html`
- `ver_tabla.html`
- `editar_fila.html`
- `admin/ver_catalogo.html`
- `catalogos/add_row.html`
- `catalogos/view.html`
